# GitHub Web Upload Guide

Follow these steps to manually upload your project to GitHub using the web interface:

1. Open your GitHub repository in your web browser.
2. Click the **Upload files** button (usually located near the "Add file" dropdown).
3. Extract `multilingual-vlm-benchmark.zip` on your local machine, and drag **all of the extracted files and folders** into the browser window. (Note: Dragging the ZIP file directly will upload the ZIP as a single binary file, so be sure to extract it and drag the contents).
4. Wait until the upload completes (this may take a moment for large datasets).
5. In the **Commit changes** box at the bottom, enter the following commit message:
   ```text
   Initial public release of multilingual-vlm-benchmark
   ```
6. Click **Commit changes**.
