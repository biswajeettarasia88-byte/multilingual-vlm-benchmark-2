# Data Collection Plan for Benchmark-v1

## Image Quality Requirements
- Minimum resolution: 1024x1024
- Occlusion limits: Text must be readable by humans
- Blur limits: No motion blur obscuring key text
- Languages & Scripts: Target multiple languages and scripts natively found in the scene.
- Scene Types: Indoor scenes, Outdoor scenes, Document images, Chart images, Receipt images, Street scenes.

## Accepted Sources
- Own photography
- Research datasets with compatible licenses
- Government open data
- Creative Commons datasets
- Public benchmark datasets allowing redistribution
- OpenStreetMap related imagery where permitted
- Community contributions

## Rejected Sources
- Pinterest
- Google Images
- Random screenshots
- Copyrighted books
- Private social media
- Images without redistribution rights
- Unknown licenses
