# Examples Directory

This directory is intended to hold sample testing inputs and baseline configurations.

## User Assets
If you have local, non-redistributable proprietary images (like scanned IDs or private documents) that you wish to test without adding them to the main dataset cache, you may place them here. 

**Note:** We do not track image binaries inside the repository directly due to size and copyright constraints.

Files to place here (ignored by git):
- `sample_signboard.jpg`
- `sample_document.jpg`
