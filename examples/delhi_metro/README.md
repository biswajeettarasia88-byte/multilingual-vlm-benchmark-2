# Reference Example: Delhi Metro Signage

This is the definitive reference example demonstrating the complete 12-file architecture required for a valid benchmark sample.

## Evaluated Challenges
- **Multilingual OCR**: Hindi (Devanagari) and English (Latin).
- **Mixed Directionality**: Left-to-right English combined with complex Devanagari ligatures.
- **Spatial Reasoning**: Deducing directional travel based on sign arrows and layout.

This directory contains the gold-standard schema definitions (`annotation.json`, `metadata.json`) alongside simulated evaluation outputs (`prediction.json`, `score.json`, `report.json`) to demonstrate the evaluation framework's data flow.
